Getting started

Choose a connection, try the sample or collect your own data.

Which edition should I choose?

Use Fabric OneLake if your team manages data in a Lakehouse: choose the notebook route for notebook collection, or the PAX route for PAX-produced Fabric OneLake tables. The Fabric OneLake PAX template download is coming soon. Use SharePoint for PAX CSV files with cloud refresh. Use Local CSV to try the sample or explore files in Desktop.

Can I try the report without an administrator or tenant data?

Yes. Download Local CSV and the three synthetic sample files. Extract the Interactions CSV from the ZIP, put all three CSVs in a local folder, then paste their full paths into the template. The sample needs Power BI Desktop, not PAX or tenant permissions.

What do I need to export my own data?

Ask IT to confirm audit logging, data access and the required collection permissions. Open PAX Cookbook Mini-Kitchen, choose AI-in-One and your destination, then follow its download and command instructions. PAX uses PowerShell 7 or later and Python 3.10 or later for preparation. Open the report template in Power BI Desktop.

Which SharePoint address should I paste?

Select the file in its document library, open Details, and copy Path. Use the full HTTPS file path, not a sharing/viewer link or the browser address bar. For Local CSV, use File Explorer Copy as path and remove surrounding quotation marks.

Fix a problem

Start here when the report is blank, a button will not respond or an export looks incomplete.

Why do report buttons not respond in Power BI Desktop?

Hold Ctrl while clicking a report button in Desktop edit mode. Published report readers use a normal click. Clear filters resets selections and expanded tables without moving to another page or changing access rights.

Why can a viewer open the report but see no data?

The report owner should check Security role membership for the semantic model, then test the viewer's sign-in. The role named Reporting hierarchy needs that sign-in to match a person in the directory. Also check dates and Minimum Group Size. The role named All data viewers gives access to the whole dataset; assign it only when that level of access is appropriate under your organization's policies.

Why is a newly enabled audit export nearly empty?

Enabling audit logging does not recover the past. Allow up to 24 hours for records to appear, then collect again. Check available history and collection dates before requesting an older period.

Why is a catalog field or agent activity blank?

Not recorded is missing Creator; Not stated is missing or generic Developer Name. A blank return rate can mean no activity or protected scope; 0% means active users with no repeats. Security Copilot usage is not tracked here, and system-generated agents are excluded by default. Check scope and the field explanation before changing data.

Where should I ask for help?

Start with your report owner or IT administrator. Tell them which data connection you use, what you were trying to do and the error message, with private details removed. You can also email the Microsoft Copilot Analytics team. Never share real audit exports, prompt content, tenant identifiers, access tokens, secrets or sensitive logs in a public issue.

Understand the numbers

Make sense of activity, license information and differences between reports.

Can I load a raw Purview export directly?

No. Use the dashboard-ready Users and Interactions from the same PAX AIO seed and its appends. If you already have raw audit and directory CSVs, the optional standalone processor can prepare them; PAX is the simpler route because it also collects and maintains the inputs.

Is the Agent 365 catalog required?

It is recommended, not required. Leave the optional Agent 365 file parameter blank for activity-only reporting. In the Fabric OneLake PAX edition, leave Load Agent365 catalog false unless a valid, synchronized Agent365 table is available. Enabling it requires access to that table and the catalog information the template expects.

Why do counts differ from Viva Insights or the admin center?

Compare the exact people, dates, time zone, license population and activity definition first. Audit coverage, timing and calculations differ from official usage reports. An audit-based all-activity prompt total is not the same metric as a Chat-only prompt headline.

Are active licensed users the same as licensed chat users?

No. Active licensed includes any recorded experience, including agent-only activity. Chat-specific charts use their own narrower population. Active plus inactive licensed reconciles to licensed directory headcount in the same scope; missing license evidence stays Unknown.

Why can paid and free counts add up to more than the total?

A person with observed license changes can belong to both populations during a selected period. Monthly paid membership includes a licensed state at any point that month. Count distinct people for totals rather than adding state rows or paid/free groups.

Does First seen tell me when a license was assigned?

No. It tells you when collection first recorded that license state. If Monday's collection shows a person without a license and Friday's shows a license, the change happened somewhere in between; the report cannot tell you the exact assignment time. History starts with what collection records and does not recover earlier changes.

Why do habit cards differ from the activity table?

The cards use the printed month before the selected range ends. Activity tables use the whole selected period. The four habit bands are always 1-5, 6-10, 11-15 and 16+ distinct active days; people with zero days are outside them.

Do agent scores measure productivity or business value?

No. Engagement combines peer-relative repeat use and conversation-depth signals. Use-case labels come from stored activity evidence, not prompt-text analysis. Confirm the explanation with the team; do not use these figures alone for employee, licensing or agent-removal decisions.

Privacy and access

Understand hidden detail, group size and who can see the data.

Why are names or By user views hidden?

Minimum Group Size defaults to 3, intentionally hiding individual activity. Keep that setting for team reporting. If your organization's privacy and employee-reporting policies permit individual reporting, the report owner can change the existing parameter to 1 under Home > Transform data > Manage parameters, apply changes and clear old person selections. Check with your privacy or HR team if you are unsure.

Can a team with only two active users show results?

Yes, if at least three eligible people belong to the selected authorized group at the default threshold. A team of 20 with two active users can show aggregate results; a team of two cannot. The normal threshold is eligible headcount, not active-user count.

Does Minimum Group Size replace access control?

No. It suppresses report display; it does not anonymize the model. Before sharing, assign appropriate RLS roles, control report/export access and protect source files, SQL and OneLake separately. Workspace Admins, Members and Contributors are not restricted like report Viewers.

Keep data current

Update the source data and keep Power BI refresh running in the right order.

How do I keep file-based data current?

Use Mini-Kitchen for both the first PAX collection and later updates. First, collect the history you need. For updates, have Mini-Kitchen create a command that adds new days to those same matching files. IT can schedule that command and refresh Power BI after the data update finishes. Mini-Kitchen creates commands; it does not run or schedule them for you.

Does scheduled refresh need a gateway?

SharePoint normally uses an organizational cloud connection without a gateway. Local or network files require a gateway that can read the same paths, or manual Desktop refresh and republishing. Fabric OneLake uses a SQL cloud connection; private networking or your organization's policies may add requirements.

First collection and ongoing updates
What is the Fabric OneLake notebook refresh order?

Run collection, then preparation. Wait for the SQL analytics endpoint to show the completed Fabric OneLake report tables and their Ready status with matching counts. Do not update tables during Power BI refresh. Configure SQL and any optional SharePoint credentials, try Refresh now, then check a scheduled refresh succeeds.

Can I use PAX-produced Fabric OneLake tables with the notebook template?

No. Use the separate Fabric OneLake PAX edition for AIO_Users, AIO_CopilotInteractions and optional Agent365 tables. It needs a completed data update, SQL synchronization and no table writes during the full Power BI refresh. The Fabric OneLake notebook edition uses different prepared tables.
