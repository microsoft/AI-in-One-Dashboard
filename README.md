## Choose your edition

| Edition | Data location | Download and setup |
|---|---|---|
| SharePoint | Processed PAX CSV files on SharePoint or an approved company HTTPS file host | [Template](https://github.com/microsoft/AI-in-One-Dashboard/releases/download/AI-in-One-Dashboard-v2.0/AI-in-One-v2.0.0-SharePoint-Template.pbit) · [File setup](sample-data/README.md) |
| Local CSV | Processed PAX CSV files on a PC or network share | [Template](https://github.com/microsoft/AI-in-One-Dashboard/releases/download/AI-in-One-Dashboard-v2.0/AI-in-One-v2.0.0-Local-CSV-Template.pbit) · [File setup](sample-data/README.md) |
| Fabric OneLake | Prepared `aio_v2_*` tables from the dashboard's notebooks | [Template](https://github.com/microsoft/AI-in-One-Dashboard/releases/download/AI-in-One-Dashboard-v2.0/AI-in-One-v2.0.0-Fabric-OneLake-Template.pbit) · [Notebook-backed setup](Fabric%20OneLake/AI-in-One%20-%20v2.0.0%20-%20Fabric%20OneLake%20Template/README.md) |
| Fabric OneLake PAX | Processed PAX PowerShell tables through SQL Import | [Template](https://github.com/microsoft/AI-in-One-Dashboard/releases/download/AI-in-One-Dashboard-v2.0/AI-in-One-v2.0.0-Fabric-OneLake-PAX-Template.pbit) · [PAX-backed setup](Fabric%20OneLake/PAX/README.md) |

Both Fabric editions remain available with distinct source contracts. The PAX-script-backed edition is not the separate Fabric-native PAX Fabric product.

Read the [report walkthrough](Report%20Screenshots.md), [Interpretation Guide](AI-in-One-v2.0.0-Interpretation-Guide.pdf), [What's New](AI-in-One-v2.0.0-Whats-New.pdf) and [Storyboard](AI-in-One-v2.0.0-Storyboard.pptx).

Source credentials, access controls and normal refresh configuration remain required. Release packaging does not certify every customer authentication setup, SQL publication/synchronization boundary or workload-performance scenario.

The original main tree is preserved unchanged in the [historical archive](_Archive/README.md).
