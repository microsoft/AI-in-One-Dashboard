Get started

From your data.
To your first useful view.

Four practical steps: prepare, collect, open and share. Your IT team can help with permissions; Mini-Kitchen helps with PAX.

Just exploring? Start with the sample.

Install Power BI Desktop (opens a new tab), download the Local CSV template and the three sample files, then extract the activity CSV from its ZIP. Open the template and paste the full paths to those CSVs. No tenant access or PAX collection is needed.

Before you collect your organization's data

  • Install current Power BI Desktop. PAX also uses PowerShell 7 or later and Python 3.10 or later; Mini-Kitchen explains the tools.
  • Ask IT to confirm audit logging is enabled, the history you need is available and the collection account has the right permissions.
  • Agree on who may see the report and whether individual activity is appropriate under your privacy and employee-reporting policies.
  • Confirm Power BI sharing licenses or capacity. Fabric OneLake routes also need suitable Fabric capacity and Lakehouse access.
You do not need to be the administrator.

Your IT team can help with collection permissions, storage and report sharing. Use the administrator checklist. Newly enabled audit logging does not recover the past; records can take up to 24 hours to appear.

02

Collect

Prepare the report's data.

Already have matching, dashboard-ready inputs from your data team? You can go straight to opening the template. Raw Purview exports are not ready-to-use report inputs.

Your PAX starting point

PAX Cookbook Mini-Kitchen

Choose AI-in-One, select where to save your data, and create the PAX command you need. Script downloads and switch explanations are right there. You run the command in your own environment; the website does not collect your data.

Open Mini-Kitchen (opens a new tab)PAX v2.0 repository (opens a new tab)

Follow the route you chose. Fabric OneLake PAX and Fabric OneLake notebooks use different tables; do not mix the two.

Fabric OneLake: notebooks

Use this route if your team wants collection and preparation inside Fabric OneLake rather than PAX.

  1. Import the audit, organization, licensing and preparation notebooks. Attach the same default Lakehouse to all four.
  2. Have IT configure the collection application's permissions and Key Vault secret access. Never put secrets in notebook cells.
  3. Run the three collectors, then the report preparation notebook. A pipeline can coordinate these steps.
  4. Wait for the prepared tables and their matching Ready status to appear in the SQL analytics endpoint. SQL can lag behind the Lakehouse update.

Fabric OneLake: PAX

Use Mini-Kitchen to configure PAX for AI-in-One and Fabric OneLake output. This route reads the processed AIO_Users and AIO_CopilotInteractions tables, with an optional Agent365 catalog. It does not use the notebook edition's preparation tables.

Let the whole PAX update finish, then wait for SQL synchronization. Do not update tables while Power BI is refreshing them.

Template download coming soon.

The Fabric OneLake PAX template is not yet available to download. Do not substitute the Fabric OneLake notebook template.

Detailed Fabric OneLake PAX setup
SharePoint
  1. In Mini-Kitchen, choose AI-in-One and your SharePoint destination. It helps with both your first collection and later updates.
  2. Download PAX from Mini-Kitchen and run the command it creates in your environment.
  3. Keep the matching Interactions and Users CSVs together. Collecting the Agent 365 catalog is recommended but optional.
  4. For each CSV, select it in SharePoint, open Details and copy Path. Do not use a sharing link or the browser address bar.

For app-only SharePoint collection, an administrator must grant access to the intended site; consent to Sites.Selected alone does not grant that access.

Detailed SharePoint setup
Local CSV
  1. In Mini-Kitchen, choose AI-in-One and a local output folder. Use it for your first collection and later updates.
  2. Download PAX there and run the command it creates. Keep the resulting matching CSV files together.
  3. In File Explorer, use Copy as path. Remove the surrounding quotation marks before pasting into Power BI.

Desktop can read the files directly. Scheduled Power BI Service refresh requires a gateway that can read the same paths.

03

Open

Open your template in Power BI Desktop.

  1. Download the template that matches your connection. Open the .pbit file in Desktop, not Excel or the browser.
  2. Enter the requested source details using the matching CSV files or Fabric OneLake connection below.
  3. Keep Minimum Group Size at 3 for team-level reporting. Use individual reporting only if your organization's privacy and employee-reporting policies allow it. Check with your privacy or HR team if you are unsure.
  4. Select Load and sign in to the source if prompted. Start on Copilot Usage Explorer and check your teams and dates.

Changing the group-size setting later?

In Desktop, select Home > Transform data > Manage parameters > Minimum Group Size. Change the existing parameter, apply changes and clear old filters. Do not create a new modeling parameter.

04

Share

Set access before you share.

Just trying the sample? You can keep it in Desktop. For a shared report, your report owner follows these steps.

  1. Publish to the intended Power BI workspace.
  2. Open the semantic model's Security settings. Add people or security groups to the appropriate named role: Reporting hierarchy for their own reporting organization, or All data viewers for full-dataset access when your policies permit it.
  3. Save and test representative viewer accounts. Share through an app or Viewer access. Workspace Admins, Members and Contributors are not restricted like Viewers.
  4. Configure source credentials and try Refresh now. Schedule later refreshes only after data collection and preparation finish.
Collect or update dataFinish preparation and synchronizationRefresh Power BI
How do I keep the data current?

PAX collection: use Mini-Kitchen for both the first collection and later updates. The first collection gets the history you choose. Later commands add new days to the same report files or Fabric OneLake tables, so you do not have to reconnect the report each time.

Make it automatic: ask IT to schedule those updates and keep the Power BI refresh after they finish. Mini-Kitchen creates the commands; it does not run or schedule them for you. The ongoing collection guide explains the details for whoever sets up the schedule.

SharePoint: the report's refresh account needs read access to the files. Leave enough time after collection for the update to finish.

Local CSV: scheduled refresh needs a gateway that can read the files. Otherwise, refresh in Desktop and republish.

Fabric OneLake: finish PAX or notebook collection and preparation, then wait for the SQL connection to show the completed data. Do not update tables while Power BI refreshes them.
