Copilot Usage Explorer

How is my team, a manager's organization or one agent using Copilot?

Fictional example data. Screenshots show individual detail; templates default to team-level reporting with Minimum Group Size 3.

Start with people, prompts and conversations, then narrow the report to the team and dates you need.

What to look for

  • Six headlines cover active users, prompts, sessions, prompts per session, active days per user and repeat users.
  • Daily prompts and sessions sit beside bold 7-day averages; month-start dots mark the Explorer averages.
  • Switch Activity by experience between sessions and prompts without changing your selected people.
  • Explore agent usage and inferred activity patterns in the same organizational and date scope.
  • Reporting team includes a manager's direct and indirect reports, excluding the manager.

TRY THIS

Open Org filters, search Reporting team for a manager, then choose your dates. In Desktop edit mode, use Ctrl+click on report buttons.

Read it in context

An inferred pattern is a clue, not an outcome. Eligible team membership, not the number of active users, determines the minimum-group check.
